## Solución segundo parcial primera parte Pilas

## Gestión librería

## Objetivo

El sistema debe permitir las siguientes acciones: 

1.	Registrar un libro y apilarlo en la pila. 
2.	Retirar el último libro registrado. 
3.	Consultar cuál es el último libro registrado usando peek(). 
4.	Mostrar todos los libros almacenados.
